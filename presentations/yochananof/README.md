# יוחננוף — מצגת הפקה

מצגת לקוח בעברית (RTL), במיתוג יוחננוף: תסריט · קאסט · מוצרים · סטוריבורד.
קובץ אחד, בלי build ובלי שרת — פותחים את `index.html` בדפדפן.

```
presentations/yochananof/
├── index.html        המצגת (עיצוב + לוגיקה). בדרך כלל לא נוגעים.
├── deck-data.js      ← כל התוכן. זה הקובץ היחיד שעורכים.
└── assets/
    ├── yochananof-logo.svg
    ├── shyow-wordmark.svg
    ├── cast/         תמונות קאסט
    ├── products/     פאקשוטים
    └── storyboard/   פריימים
```

## איך מוסיפים חומרים

1. שמים את הקבצים בתיקייה המתאימה תחת `assets/`.
2. פותחים את `deck-data.js` ומוסיפים את הנתיב בשדה `img` של הפריט:

```js
{ img: 'assets/storyboard/01.jpg', scene: 1, shot: 'רחב', move: 'טראק פנימה', dur: 2, desc: '…' }
{ name: 'האגיס', meta: 'Extra Care · מידה 2', img: 'assets/products/diapers.jpg', frames: [5, 6] }
```

3. מרעננים את הדפדפן. פריט בלי `img` מוצג כמשבצת "ממתין לחומר" — אפשר לבנות בשלבים.

**קאסט** מקבל מערך אופציות במקום תמונה בודדת. כל האופציות מוצגות זו לצד זו,
בבלוק נפרד לכל דמות, וממוספרות "אופציה 1/2/3" כדי שאפשר יהיה להתייחס אליהן בשיחה:

```js
{ name: 'האמא', role: 'ראשי', picked: true, scenes: [4], note: '…',
  imgs: ['assets/cast/mom-1.jpg', 'assets/cast/mom-2.jpg'] }
```

`picked: true` = הליהוק נסגר: האופציה הראשונה מסומנת **"נבחר"** במסגרת צהובה,
והכותרת מציגה "ליהוק נבחר". אחרת מוצג מספר האופציות הפתוחות.
`role: 'ראשי'` מקבל תג צהוב מלא; כל ערך אחר מקבל תג מתאר.

שום תוכן לא מוסתר מאחורי לחיצה — המצגת נקראת במלואה גם כקובץ PDF.

**עמודת השמע** בתסריט מפוצלת לשלושה סוגים, כל אחד בצבע משלו:
`sfx` מוזיקה וסאונד (לבן) · `vo` קריינות (צהוב) · `sup` טקסט על המסך (אדום).

**גדלים מומלצים:** קאסט 3:4 (900×1200), פאקשוט ריבוע על רקע לבן/שקוף (1000×1000),
סטוריבורד 16:9 (1920×1080). JPG לצילומים, PNG לפאקשוטים עם שקיפות.

## מה מתחשב לבד

- **טיימקוד** — מחושב מסכום ה־`dur` של הסצנות. מזינים רק אורך סצנה.
- **בדיקת אורך** — אם סכום הסצנות ≠ `duration`, מופיעה התראה אדומה מתחת לרצועת הזמן.
- **קישורים** — שבב `פריימים` בתסריט פותח את הפריים; שבב `סצנות` בקאסט קופץ לשורה בתסריט.

## לפני שליחה ללקוח

בראש `deck-data.js`: `draft: false` — מסיר את תווית **"מצב תבנית — לא לשליחה"**.

## הצגה

| מקש | פעולה |
|---|---|
| `PageDown` / `PageUp` | פרק הבא / הקודם (עובד עם שלט מצגת) |
| `1`, `2`, `3`… | קפיצה לפרק לפי סדרו ב־`sections` |
| `←` `→` | מעבר בין פריימים כשתיבת התצוגה פתוחה |
| `Esc` | סגירת תיבת התצוגה |

**PDF:** Ctrl+P → שמירה כ־PDF. גיליון ההדפסה הופך את המצגת לרקע לבן, מסיר ניווט,
פותח כל פרק בעמוד חדש, מגדיל את הסטוריבורד לשתי עמודות ומונע חיתוך של בלוק באמצע.
אין צורך לסמן "גרפיקות רקע" — הצבעים מותאמים גם בלעדיה.
סדר הפרקים נקבע במערך `sections` בראש `deck-data.js`.

**קישור ישיר לפרק:** `index.html#storyboard` (וכן `#script`, `#cast`, `#products`).

## מצגת ללקוח נוסף

מעתיקים את התיקייה, מחליפים את הלוגו ב־`assets/`, ומעדכנים את שלושת צבעי המותג
בראש `index.html` (`--y`, `--r`, `--ink`) ואת התוכן ב־`deck-data.js`.
`wordmark` בראש קובץ הנתונים = קובץ לוגו ההפקה לפוטר; אם הוא ריק, מוצג שם ההפקה בטקסט.
